1. 로고 시안 A·B·C 중 어느 쪽

A · 원형 엠블럼

  • 중요간판·컵 도장에 잘 어울림
  • 핵심작게 줄이면 글자가 뭉개짐

B · 글자만추천

  • 핵심앱 아이콘·SNS 프로필 크기에서도 읽힘
  • 참고개성이 덜해 보일 수 있음

C · 그림 + 글자

  • 중요무엇을 파는 곳인지 바로 보임
  • 중요가로로 길어 정사각 자리에 안 맞음
